# Development Update Assets

These are the images of **real software** in this repository: dated captures of
the current Ainix prototype that support the development updates.

They are captures of the actual hosted canvas shell. They are **not** production
GUI, public-release, native shell, desktop-replacement, AR, or VR screenshots —
they show the prototype as it actually runs.

## 2026-06-05

- `hosted-shell-ui-prototype.png` — the hosted canvas shell UI rendering brokered
  shell/canvas state (fixture mode), with the selection inspector and the
  proposal/approval action flow.
- `three-spatial-renderer-prototype.png` — the opt-in Three.js spatial renderer
  adapter over the same brokered DTO frame.
