# Archived concepts

These are **superseded** exploratory concepts, kept for history.

The current direction is a **desktop 2D** surface (see
[`../ui-deck/`](../ui-deck/)). Spatial/AR/VR, touch, and mobile form factors are
out of scope, and the "infinite canvas as the primary surface" idea has been
retired in favor of focused, purpose-built surfaces for *acting* on and
*verifying* agent work.

- `gui-concepts/` — early aspirational interface art (AR/VR, touch, mobile,
  infinite canvas, cross-media). Not a current target.
- `03-future-canvas-control-surface.png` — an earlier "canvas as control surface"
  explainer, superseded by the UI deck.
